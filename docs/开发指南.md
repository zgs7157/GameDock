# 开发指南

面向想参与 GameDock 开发的贡献者。先读 README 了解项目定位。

## 技术栈

- C# / .NET 8
- `GameDock.Core`：核心库（`net8.0`，跨平台）
- `GameDock.Cli`：命令行（`net8.0`）
- `GameDock.App`：WinForms GUI（`net8.0-windows`）
- `GameDock.Core.Tests`：xUnit 单元测试

代码风格：文件名即类型名；公开 API 带中文 XML 注释；禁用隐式 `object.ToString()` 拼接路径，统一用 `Path.Combine`。

## 代码结构

```
GameDock.Core/
├── Models/      # 反序列化模型（JsonPropertyName 与上游 JSON 字段一一对应）
├── Mirrors/     # IMcMirror 接口 + 官方/BMCLAPI/自定义实现 + 注册表 + 健康检测
├── Services/    # 下载引擎与编排
│   ├── DownloadManager.cs    # 并发下载：候选URL/重试/sha1校验/跳过已存在
│   ├── McJsonClient.cs       # JSON/文本请求：镜像回退
│   ├── VersionDownloader.cs  # 版本下载编排（清单→meta→组装→下载→导入）
│   ├── ImportService.cs      # .minecraft 目录布局
│   ├── RuleEvaluator.cs      # 库的 os/arch 规则评估
│   └── NativesExtractor.cs   # natives 解压
├── Loaders/     # Forge/Fabric/NeoForge/OptiFine
└── Config/      # config.json
```

## 关键设计

### 镜像（IMcMirror）

```csharp
public interface IMcMirror
{
    string Key { get; }          // official / bmclapi / 自定义
    string DisplayName { get; }
    string MetaBase { get; }     // 元数据根
    string AssetsBase { get; }   // 资源根
    string LibrariesBase { get; }// 库根
    string RewriteUrl(string originalUrl); // 官方地址 → 本镜像地址
}
```

下载候选 = `[原始URL] + 各镜像 RewriteUrl(原始URL)`，去重保序（见 `Util/UrlCandidates.cs`）。

### 下载（DownloadEntry）

```csharp
new DownloadEntry {
    Kind = "library",          // client/server/library/native/asset/installer...
    DisplayName = "xxx.jar",
    DestPath = "...",          // 落盘路径
    Sha1 = "...",              // 校验用，可为 null
    Size = 12345,              // 校验用，可为 0
    UrlCandidates = [...],     // 候选地址
}
```

### 加载器扩展流程（以新增 Quilt 为例）

1. `Models/` 加 Quilt 的 meta 模型（如有）；
2. `Loaders/QuiltService.cs`：实现 `GetLoaderVersionsAsync` + `InstallAsync`（Fabric 已给出可参照的“meta 生成版本 JSON + inheritsFrom”模式）；
3. `Cli/Program.cs` 注册子命令；`App/MainForm.cs` 的加载器页加类型；
4. 补单元测试（解析 + URL 重写）并在 `tests/` 下运行。

## 测试

```powershell
dotnet test tests/GameDock.Core.Tests
```

新增模型/规则/路径逻辑必须带测试。测试不依赖网络（样本 JSON 内联在代码里）。

## 提交与 PR

- 保持 `.gitignore` 不含 `bin/ obj/`；
- 提交信息用中文，描述做了什么（如 `feat: 支持自定义镜像测速`）；
- CI（`.github/workflows/build.yml`）会在 Windows 上自动 build + test，通过后再合入。

## 发布

```powershell
# 单文件 GUI
dotnet publish src/GameDock.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
# CLI
dotnet publish src/GameDock.Cli -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

发布物在 `src/GameDock.App/bin/Release/net8.0-windows/win-x64/publish/`。

# GameDock 使用说明

本文覆盖 GUI 与 CLI 的完整用法。构建方法见 README，镜像机制见《镜像源配置》。

## 一、图形界面（GameDock.exe）

### 主界面布局

- **顶部栏**：镜像源下拉框（默认 BMCLAPI）+「测速」按钮；启动器目录输入框 +「浏览…」。
- **左侧**：版本列表。筛选按钮（全部 / 正式版 / 快照）+ 搜索框 +「刷新」。
- **右侧「原版下载」页**：勾选 客户端 / 服务端 / 资源(assets) / natives，点「下载并导入」。
- **右侧「加载器」页**：选 MC 版本 → 选类型（Fabric/Forge/NeoForge/OptiFine）→「获取加载器版本」→ 选版本 →「下载加载器」。
- **底部**：状态栏 + 进度条 + 日志（黑色区域，滚动查看）。

### 操作步骤

1. 顶部选镜像源（被封时点「测速」挑可用源，或切到自定义镜像）。
2. 确认启动器目录：默认 `%APPDATA%\.minecraft`，可浏览选择（PCL2/HMCL 安装目录）。
3. 原版：左侧点选版本 → 勾选内容 → 下载并导入。
4. 加载器：Fabric 无需 Java；Forge/NeoForge/OptiFine 若勾选「自动运行」需要本机 Java 8+，否则只下载安装器，手动运行。

### 日志说明

日志级别：`INFO` 正常进度、`WARN` 重试/跳过、`ERROR` 失败原因。日志框上限约 20 万字符，自动滚动。

## 二、命令行（gamedock）

```powershell
gamedock help                      # 帮助
gamedock list [--type release|snapshot|all] [--contains 关键字] [--mirror key]
gamedock download <版本ID|latest:release|latest:snapshot> [选项]
gamedock fabric <MC版本> [--loader 版本] [选项]
gamedock forge <MC版本> [--version Forge版本] [选项]
gamedock neoforge [--mc MC版本] --version <版本> [选项]
gamedock optifine <MC版本> --index N [选项]
gamedock mirror list|add|remove|health
gamedock config [--mc-dir 目录] [--mirror key] [--threads N]
gamedock launch-dirs              # 探测本机启动器目录
```

### download 选项

| 选项 | 说明 |
|---|---|
| `--mc-dir <目录>` | 导入到指定 .minecraft 目录（默认取配置） |
| `--mirror <key>` | 使用指定镜像（official / bmclapi / 自定义） |
| `--server` | 同时下载服务端 |
| `--no-assets` | 不下载资源文件（省流量） |
| `--no-client` | 不下载客户端 jar |
| `--no-natives` | 不解压 natives |
| `--no-import` | 只下载不写入启动器目录 |
| `--threads N` | 覆盖并发线程数 |
| `--config <path>` | 使用指定配置文件 |

### 示例

```powershell
# 1) 查询
gamedock list --type snapshot --contains 25w
gamedock mirror health

# 2) 下载原版 1.21.4 到 PCL2 的 .minecraft
gamedock download 1.21.4 --mc-dir "D:\PCL\.minecraft"

# 3) 最新正式版 + 服务端，不下载资源
gamedock download latest:release --server --no-assets

# 4) Fabric 安装（自动带原版基础版本）
gamedock fabric 1.21.4

# 5) Forge 下载并自动安装
gamedock forge 1.20.1 --version 47.2.0 --run

# 6) NeoForge
gamedock neoforge --mc 1.20.4            # 先列出版本
gamedock neoforge --version 20.4.237 --run

# 7) OptiFine：先列表再选
gamedock optifine 1.21.4
gamedock optifine 1.21.4 --index 0 --run

# 8) 配置
gamedock config --mc-dir "D:\MC\.minecraft" --mirror bmclapi --threads 16
```

## 三、配置文件

路径：`%APPDATA%\GameDock\config.json`；镜像列表：`%APPDATA%\GameDock\mirrors.json`。

```json
{
  "McDir": "C:\\Users\\you\\AppData\\Roaming\\.minecraft",
  "Mirror": "bmclapi",
  "Threads": 8,
  "RetryCount": 3,
  "DownloadAssets": true,
  "DownloadServer": false,
  "AutoImport": true,
  "AutoRunInstaller": false,
  "TimeoutSeconds": 60
}
```

删除配置文件即可恢复默认。

## 四、常见问题

| 问题 | 处理 |
|---|---|
| 下载很慢 | 换镜像（`gamedock mirror health`）、加大 `--threads` |
| 版本列表刷不出来 | 网络问题或镜像失效，换 `--mirror official` 试试 |
| Fabric 版本打不开 | 确认原版基础版本在同一个 .minecraft 目录（工具会自动导入） |
| Forge 安装器没反应 | 手动运行：`java -jar forge-*.jar --installClient <目录>` |
| 游戏启动后缺资源 | 重新下载并勾选「资源(assets)」 |

> 提示：资源文件（assets）总量约 200MB～1GB，首次下载请耐心等待；之后增量跳过。

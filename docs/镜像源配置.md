# 镜像源配置

GameDock 的“防封杀”核心是**多镜像候选 + 自动回退**。

## 工作原理

下载任何文件时，工具按此顺序生成候选地址并逐个尝试：

1. **原始地址**（版本 JSON 里声明的官方地址）；
2. **每个已注册镜像的重写地址**（按配置的偏好顺序）。

单个地址失败 → 重试（`RetryCount` 次）→ 换下一个候选 → 全部失败才报错。
所以只要列表里还有一个可用镜像，下载就不会中断。

## 内置镜像

| key | 名称 | 元数据端点 | 说明 |
|---|---|---|---|
| `official` | Mojang 官方源 | piston-meta.mojang.com | 境外直连，境内可能慢 |
| `bmclapi` | BMCLAPI 镜像 | bmclapi2.bangbang93.com | 国内常用，兼容官方路径 |

BMCLAPI 同时代理以下路径（自动重写，无需配置）：
- `/mc/game/version_manifest_v2.json`（版本清单）
- `/assets/...`（资源对象）
- `/libraries/...`（库）
- `/maven/...`（Forge maven）
- `/fabric-meta/...`（Fabric meta）
- `/forge/...`（Forge promotions）
- `/optifine/<mc>`（OptiFine 列表）

## 自定义镜像

新增（会写入 `%APPDATA%\GameDock\mirrors.json`）：

```powershell
gamedock mirror add <key> <显示名称> <BaseUrl>
gamedock mirror add mymc 我的镜像 https://mc.example.com
```

规则：`BaseUrl` 需要提供与官方结构兼容的路径，即：
- `<BaseUrl>/mc/game/version_manifest_v2.json` 可访问
- `<BaseUrl>/assets/...`、`<BaseUrl>/libraries/...` 可用

若不兼容官方结构（例如只代理 assets），仍可加入——工具会尝试原始地址后走重写地址，重写地址失败不会影响其他候选。

选用镜像：

```powershell
gamedock download 1.21.4 --mirror mymc     # 单次指定
gamedock config --mirror mymc               # 全局指定
```

删除 / 测速：

```powershell
gamedock mirror remove mymc
gamedock mirror health                      # 全部镜像延迟测速
```

## 自建反代（进阶）

如果常用镜像都被封，可以用一台境外/境内 VPS 反代官方端点：

```nginx
# Nginx 示例：/assets → resources.download.minecraft.net，/libraries → libraries.minecraft.net
location /assets/    { proxy_pass https://resources.download.minecraft.net/assets/; }
location /libraries/ { proxy_pass https://libraries.minecraft.net/libraries/; }
```

```powershell
gamedock mirror add myproxy 自建反代 https://你的域名
```

## 注意事项

- 镜像地址必须支持 **HTTPS**（Mojang 校验与境内网络环境均要求）。
- 镜像“不可达”时请勿删除，保留在列表里作为兜底候选即可。
- 请仅添加你信任的镜像；第三方镜像可能篡改文件，工具会以 **SHA1 校验**拦截被篡改的下载。
